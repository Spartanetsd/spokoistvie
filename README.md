# Спокойствие сильнее страха

**Особиста система психологічної стійкості — версія 2.0.**
Ясність. Самовладання. Повернення.

Текстовий офлайн-застосунок (PWA) для iPhone: саморегуляція, самогіпноз, відновлення після чергування. Без аудіо, звуків, реклами, реєстрації та сервера. Інтерфейс — російською, перемикається на українську.

---

## ⚠️ Безпечне використання

- Застосунок **не призначений** для читання під час переміщення небезпечною територією, керування транспортом, спостереження за повітряною обстановкою, поводження зі зброєю чи надання невідкладної допомоги.
- Читай лише там, де можна безпечно зупинитися. Глибоке розслаблення та практики із заплющеними очима — лише поза безпосередньою небезпекою.
- Застосунок не попереджає про дрони чи обстріли і не дає порад щодо маршрутів, пересування, зброї чи тактики.
- Кнопка **✕** у лівому верхньому куті будь-якого екрана читання — миттєвий вихід.

## Режими

| Режим | Для чого |
|---|---|
| **Перед выходом** | Коротке налаштування в безпечному місці: 30 / 60 / 120 с, великий шрифт, по одному абзацу, ручне перемикання. Після часу — екран «Время вышло». |
| **Чужие провокации** | Саморегуляція після напруженого спілкування. Метафора «Пустая лодка». Тексти додаєш сам. |
| **Мы вместе** | Власні тексти, фільтр коротких і довгих практик, своє фото, закріплення улюблених. |
| **После возвращения** | Тривалі практики, режим концентрації, необов’язкова оцінка напруження до/після. |
| **Сон** | Нічний екран: чорне тло, приглушений текст, жодних анімацій, спалахів і звуків. |
| **Моя библиотека** | Усі тексти: створення, редагування, видалення з підтвердженням, імпорт TXT/Markdown, вставлення з Нотаток, режими, теги, пошук, сортування, резервна копія. |

**Три способи читання** (перемикач угорі): Книга — плавне прокручування (з автопрокручуванням і паузою), Абзац — кнопки «Назад» / «Далее», Предложение — велике речення, перехід дотиком.

**Aa** у читанні — розмір шрифту, міжрядковий інтервал, ширина тексту, тема, контраст, швидкість автопрокручування.
**Око** — режим концентрації: ховає все, крім ✕. Дотик праворуч — далі, ліворуч — назад.
Місце читання запам’ятовується; на головному екрані — картка «Продолжить».

## Що в архівах

- **spokoistvie-site** — готовий сайт. Завантажується на GitHub без збірки. Найпростіший шлях з iPhone.
- **spokoistvie-kod** — повний вихідний код: React + TypeScript + Vite, service worker, IndexedDB, GitHub Actions.
- **moi-teksty.json** — твої тексти для імпорту. **Не завантажуй його в репозиторій.**

---

## Встановлення з iPhone — готовий сайт (рекомендовано)

1. github.com → **+** → **New repository** → назва `spokoistvie` → **Public** → **Create repository**.
   (GitHub Pages для приватного репозиторію потребує платного тарифу.)
2. У застосунку «Файли» тапни по архіву `spokoistvie-site` — він розпакується в папку.
3. У репозиторії: **Add file → Upload files → choose your files** → виділи **всі файли** з папки → **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: Deploy from a branch** → Branch **main**, папка **/ (root)** → **Save**.
5. Через 1–2 хвилини сайт буде за адресою `https://ТВІЙ-ЛОГІН.github.io/spokoistvie/`.
6. Відкрий адресу в **Safari** → **Поділитися** → **На початковий екран** → **Додати**.
7. Перший раз відкрий із інтернетом — застосунок збереже себе в кеш. Далі працює повністю офлайн.

## Варіант із вихідним кодом (React + TypeScript + Vite)

1. Створи репозиторій (окремий або замість попереднього).
2. **Upload files** — усі файли з архіву `spokoistvie-kod` (вони лежать плоско, без папок).
3. **Add file → Create new file** → у полі назви набери `.github/workflows/deploy.yml` (скісні риски самі створять папки) → встав увесь текст файлу `deploy.yml` → **Commit changes**.
4. **Settings → Pages → Source: GitHub Actions**.
5. Вкладка **Actions** → дочекайся зеленої позначки (1–2 хв). Надалі кожне завантаження файлів збирає й публікує сайт автоматично.

Файл `deploy.yml` у корені після цього можна видалити — він не заважає.

## Імпорт твоїх текстів

**З резервної копії (твої 8 текстів):**
1. Збережи `moi-teksty.json` у «Файли».
2. Застосунок → **Моя библиотека → Копия → Восстановить из копии** → обери файл → **Добавить к текущим**.

Тексти зберігаються без змін. Режими й теги вже розставлені — змінити можна олівцем у списку.

**TXT і Markdown:** Библиотека → **Импорт** → обери один або кілька файлів. Перший рядок стає назвою, текст зберігається повністю.

**З Нотаток Apple:** скопіюй текст у Нотатках → Библиотека → **Вставить** (iOS попросить дозвіл «Вставити»). Або **Новый текст** → утримуй поле тексту → **Вставити**.

**Розставити по режимах:** у будь-якому режимі кнопка **Из библиотеки** — відміть потрібні тексти.

Форматування: порожній рядок — новий абзац; `**так**` — виділення; рядок `⸻` — роздільник; рядок, що починається з `#`, — заголовок.

## Резервне копіювання

Сховище браузера не гарантує безстрокового зберігання: iOS може очистити дані сайту, який довго не відкривали (застосунок на початковому екрані захищений краще, але не повністю).

- **Настройки → Резервная копия → Сохранить копию (JSON)** → у меню «Поділитися» обери **Зберегти у Файли**.
- Роби копію після кожної зміни текстів. Якщо копії не було 14 днів, головний екран нагадає.
- Відновлення: **Восстановить из копии** → **Добавить к текущим** або **Заменить всё**.

У копію входять тексти, місця читання, налаштування, герб, фото «Мы вместе», оцінки напруження.

## Оновлення застосунку

Завантаж нові файли поверх старих → Commit. Відкрий застосунок: оновлення завантажиться у фоні й з’явиться під час наступного запуску. Дані не зникають.

## Герб

**Настройки → Герб на главном экране → Загрузить изображение.** Найкраще — PNG із прозорим тлом.

---

## Приватність

- Немає сервера, бази даних, аналітики, реклами, платних сервісів.
- Тексти, фото й оцінки зберігаються лише в IndexedDB на цьому пристрої та у твоїх резервних копіях.
- Репозиторій містить лише інтерфейс і назви режимів — жодних особистих текстів, маршрутів, адрес чи графіків.
- Не завантажуй у публічний репозиторій `moi-teksty.json` чи будь-які резервні копії: їх видно всім.
